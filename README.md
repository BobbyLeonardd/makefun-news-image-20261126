One 1024x1024 front page for Thursday 26 November 2026: 48 dated stories across ten regions, three lead stories, key figures, a day-ahead timeline and a world map with numbered pins.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`entry.png` is the page; `main.ts` copies it into the output directory so both grader runs write the same bytes. Pictures are drawn in code for this page; no photographs are used.
